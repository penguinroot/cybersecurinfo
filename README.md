# cybersecurinfo
## Description du Projet
CyberSécurInfo est un site web éducatif dédié à la sensibilisation à la cybersécurité. Il fournit des informations sur les bonnes pratiques en matière de sécurité en ligne, les risques associés à l'utilisation d'Internet, et des tests interactifs pour évaluer les connaissances des utilisateurs.

## Fonctionnalités
- **Bonnes Pratiques en Cybersécurité** : Une section dédiée aux conseils sur l'utilisation de mots de passe, l'authentification à deux facteurs, les mises à jour logicielles, la confiance en ligne, les sauvegardes, et la prudence sur les réseaux sociaux.
- **Risques en Cybersécurité** : Informations sur les menaces telles que le phishing, les ransomwares, et les spywares, avec des conseils de prévention.
- **Testez-vous** : Un test interactif qui simule une situation de cyberattaque pour évaluer la réactivité des utilisateurs face à des menaces.

## Technologies Utilisées
- **HTML** : Structure de base du site.
- **CSS** : Styles et mise en page.
- **JavaScript** : Interactivité et gestion des événements.
- **Fonts** : Utilisation de polices personnalisées pour améliorer l'esthétique du site.

## Installation
1. Clonez le dépôt :
   ```bash
   git clone https://github.com/votre-utilisateur/CyberSecurInfo.git
   ```
2. Accédez au répertoire du projet :
   ```bash
   cd CyberSecurInfo
   ```
3. Ouvrez le fichier `index.html` dans votre navigateur pour visualiser le site.

## Structure du Projet

    ├── Fonts/                   # Dossier contenant les polices personnalisées
